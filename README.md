# 雪條棍機械人二維模擬

用雪條棍、橡筋及曲柄組成的平面機構模擬。網頁、樣式、圖形及物理運算全部放在 `index.html`，不需安裝套件、建置或連接網絡。

## 開啟

下載 repo 的 ZIP 並解壓，或使用 Git 複製專案，然後用瀏覽器開啟 `index.html`。

## 操作

- 選擇 G、A、P、J 或 O 部件，再用對應 slider 調整；圖中會短暫標示正在調整的位置。
- 在 P 面板拖動兩個滑塊，設定白棍的最低及最高角度，並預覽相應姿勢。
- 拖動 O 或調整 O 的位置，圓銷 Q 碰到白棍會推動白棍；碰到 P 擋位時停止移動。
- 按住 Q 順時針拖動，可按自己的速度連續旋轉；亦可輸入順時針累計轉角，或按「啟動曲柄」自動旋轉。
- 「放手」讓白棍在橡筋及重力作用下運動；Q 離開後不會拉住白棍。
- 「分析一圈」預測下一圈的白棍角度及掃過範圍：紫色表示曲柄推動，橙色表示橡筋拉回，灰色表示其他離開接觸的狀態。若受阻，會顯示停止原因及尚未到達的曲柄角度。
- 「設為初始配置」儲存目前設定；「還原配置」返回已儲存的初始設定。

設定保存在目前瀏覽器的本機儲存空間。不同網址、檔案位置或瀏覽器的設定分開保存，搬動檔案不會自動帶走舊設定。

## 機構尺寸及約束

| 項目 | 設定 |
| --- | --- |
| 兩支白棍及綠色長棍 | 每支 114 × 10 mm |
| 固定底板 | 長 210 mm |
| 兩支白棍 | 接合位置及相對角度固定，共同繞 P 旋轉 |
| 白棍角度範圍 | −50° 至 50°，可用雙滑塊收窄 |
| 白棍 0° | 原始設計姿勢，並非水平線 |
| 曲柄 O–Q | 固定長 21 mm，只順時針旋轉 |
| O 高度 | 距底板上邊至少 21 mm |
| 橡筋 A 端 | A 斜棍與底板上邊的左側凹角 |
| 橡筋 B 端 | 兩支白棍上方的外沿交點 |

固定件在運動時保持位置，調整 P 不會觸發畫面自動縮放。曲柄自動旋轉預設 30 rpm，動畫以 0.25 倍速展示；手動旋轉由拖動速度決定。

## 物理模型

兩支白棍視為同一剛體。橡筋只在拉長時施力；圓銷 Q 與棍邊作無摩擦、不反彈的單向接觸，P 角度限制視為不反彈的硬擋位。

示例參數：兩棍共 40 g、橡筋原長 100 mm、彈性係數 100 N/m、阻尼 0.0003 N·m·s、重力加速度 9.81 m/s²。這些參數未按實物校準；模型未計橡筋繞棍長度、摩擦，以及曲柄桿身、固定件與橡筋的碰撞。曲柄桿身視為位於另一層。

掃過範圍用兩支實際闊度的棍身輪廓顯示。分析以目前姿勢及轉速預測下一圈；下一圈或手動變速時，結果可能不同。

## 程式檢查

安裝 Node.js 後，在專案目錄執行：

```sh
node check_simulation.cjs
```

只使用 Node.js 內建模組，無需 `npm install`。檢查物理約束、碰撞、角度限制、掃過範圍、本機儲存及實際 HTML 事件處理；DOM 使用模擬物件，並非真實瀏覽器畫面驗收。
