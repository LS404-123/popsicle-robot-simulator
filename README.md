# 雪條棍機械人二維模擬

用雪條棍、橡筋及曲柄組成的平面機構模擬。網頁、樣式、圖形及物理運算全部放在 `index.html`，不需安裝套件、建置或連接網絡。

## 開啟

下載 repo 的 ZIP 並解壓，或使用 Git 複製專案，然後用瀏覽器開啟 `index.html`。

## 操作

- 直接拖 O 移動曲柄圓心，拖 Q 順時針試動；Q 碰到白棍會推動佢，離開後由橡筋拉回。
- 拖白棍可繞 P 調整姿勢；點 P，再拖圖上的「下限／上限」把手設定可轉角度。
- 開啟「調整結構」：拖綠棍移位、拖綠棍末端轉角、拖 A 的把手轉角；拖 P 沿綠棍移位，拖 J 沿白棍 1 調接合。拖白棍 1／2 沿棍滑動，分別改 P／J 在棍上的位置；選白棍 2 後拖末端把手改夾角。
- 「數值」提供目前部件的精確輸入；只保留曲柄速度 slider，可即時調整 0–120 rpm。圖上的把手可用 Tab 選取、方向鍵調整，Shift 加快。
- 「啟動曲柄」是主操作。「更多」內有放手回拉、分析一圈及掃過範圍、還原、保存本機初始配置及重新置中。
- 畫布佔滿 iPad 橫直向的主要空間。數值及分析浮在畫面上，不壓縮模型；模型按目前機構建立固定視野，調 P 或曲柄不會自動縮放，大幅改結構後可自行重新置中。

「設為初始配置」及一般試調只保存在目前瀏覽器的本機儲存空間，不會自動上傳 GitHub。不同網址、檔案位置或瀏覽器的設定分開保存，搬動檔案不會自動帶走舊設定。

GitHub 共用初始配置寫在 `index.html` 的 `publishedInitial`；更新並發布程式後，未保存本機配置的裝置會使用這套設定。本機有效初始配置優先，其次是本機上次試調；沒有有效本機配置才使用共用初始配置。

目前共用配置從使用者 Chrome 頁面記錄；O 座標由圖中底板的 210 mm 比例換算，保留畫面輸出前的精度。Q 按最新要求固定直徑 3 mm。

## 機構尺寸及約束

| 項目 | 設定 |
| --- | --- |
| 兩支白棍及綠色長棍 | 每支 114 × 10 mm |
| 固定底板 | 長 210 mm |
| 兩支白棍 | 接合位置及相對角度固定，共同繞 P 旋轉 |
| 白棍角度範圍 | 可用圖上把手設定 −50° 至 50°，共用初始範圍為 −9.8° 至 50° |
| 白棍 0° | 原始設計姿勢，並非水平線 |
| 曲柄 O–Q | 固定長 21 mm，只順時針旋轉 |
| 圓銷 Q | 直徑 3 mm（半徑 1.5 mm） |
| O 高度 | 距底板上邊至少 21 mm |
| 橡筋 A 端 | A 斜棍與底板上邊的左側凹角 |
| 橡筋 B 端 | 兩支白棍上方的外沿交點 |

固定件在運動時保持位置，調整 P 不會觸發畫面自動縮放。曲柄自動旋轉預設 60 rpm，以實時速度播放；頂部速度 slider 可在運轉時調整 0–120 rpm，設為 0 會停止曲柄旋轉；手動旋轉由拖動速度決定。

## 物理模型

兩支白棍視為同一剛體。橡筋用固定原長的預拉模型，在目前配置的整個可轉範圍保持拉緊；圓銷 Q 與棍邊作無摩擦、不反彈的單向接觸，P 角度限制視為不反彈的硬擋位。

示例參數：兩棍共 40 g、橡筋原長上限 90 mm（每次改結構或角度範圍時，按最短 A–B 距離的 80% 自動縮短）、彈性係數 180 N/m、阻尼 0.0003 N·m·s、重力加速度 9.81 m/s²。這些參數未按實物校準；模型未計橡筋繞棍長度、摩擦，以及曲柄桿身、固定件與橡筋的碰撞。曲柄桿身視為位於另一層。

掃過範圍用兩支實際闊度的棍身輪廓顯示。分析以目前姿勢及轉速預測下一圈；下一圈或手動變速時，結果可能不同。

## 程式檢查

安裝 Node.js 後，在專案目錄執行：

```sh
node check_simulation.cjs
```

只使用 Node.js 內建模組，無需 `npm install`。檢查物理約束、碰撞、角度限制、掃過範圍、本機儲存及實際 HTML 事件處理；DOM 使用模擬物件，並非真實瀏覽器畫面驗收。
